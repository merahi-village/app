# mOne — Kheti • Go Green • Merahi

GitHub-ready Android app. Upload the contents of this folder to the repository root (or keep it in a dedicated app repository).

## Build APK on GitHub
1. Open Actions → Build mOne Android APK → Run workflow.
2. Download the `mOne-android-apk` artifact.
3. For a permanent public download, push a tag such as `v1.0.0`; GitHub Actions will attach the APK to Releases.

Package ID: `com.merahi.mone`
